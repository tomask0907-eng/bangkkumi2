# 방봄 시연 영상 기획 요청서

> 이 문서를 받는 AI(Gemini)에게: 아래 서비스 "방봄"의 **시연 녹화 영상 기획안**을 만들어 주세요.

> 고친 날: 2026-11-27. 그림 18장은 모두 이날 사이트에서 새로 찍었어요 (PC 1440×900, 휴대폰 390×844)

## 1. 서비스 한 줄 소개

**방봄 (Bangbom) — "따져 보고, 살아 보고, 고르는 집"**
대구에서 집을 구하는 청년이 **내 조건(나이·소득·모은 돈·월 예산)** 을 넣으면,
받을 수 있는 대출·지원을 대신 따져 주고, 요건이 맞는 집을 지도에서 밝혀 주고,
평면도·3D로 방 안까지 미리 살아 보게 해 주는 **온라인 모델하우스**예요.

- 출품: 2026 안산대학교 해커톤 (대구 계명문화대학교 학생 4명 팀)
- 시연 대상: 심사위원
- 말투: 쉬운 존댓말(해요체), 짧고 다정하게

## 3. 지금 실제로 작동하는 기능 (화면을 그대로 녹화해도 되는 것)

1. **홈 5화면**: 히어로 → 문제 → 해결 1 → 해결 2 → 시작하기 (그림 01~05). 시작하기에는 단지마다 실제 아파트처럼 들쭉날쭉한 평면도 카드가 옆으로 넘어가요
2. **조건 입력 8문항**: 한 화면에 한 문항씩, 금액은 원 단위로 세 자리마다 쉼표가 들어가요
3. **판정 결과**: 대출·지원마다 요건 충족 / 확인 필요 / 미충족, 같이 못 받는 지원 거르기, 0곳이면 "이렇게 하면 열려요" 안내 (그림 06)
4. **2.5D 지도**: 대구 9개 구·군 전체에 회색 배경 아파트 단지와 건물이 빽빽하게 서 있고, 그 사이에 판정 대상 단지(주황·베이지 띠)가 놓여 있어요 (그림 16). 조건이 맞는 단지는 저녁 톤 지도에서 창문에 불이 켜져요. 단지를 누르면 가까이 다가가 지하철역·병원·공원까지 선으로 이어져요
5. **단지 카드**: 지원 반영 월 부담(원 단위), 계산 내역, 적용·빠진 지원, 계약 전 체크리스트, 신청 링크. **크게 보기**도 돼요 (그림 07)
6. **집 보기**: 집 전체 평면도 → **3D 위에서 돌려 보기** → **3D 안에서 걷기**(방을 골라 서 보기) (그림 17, 08, 09, 18)
   - 평면도는 실제 아파트처럼 바깥선이 들쭉날쭉하고 거실 앞에 발코니가 있어요. 마루·타일 무늬, 문 열림, 창문, 주방 조리대·냉장고, 욕조·변기·세면대가 그려져 있고, 위·왼쪽에 건축 도면식 치수선(10.8 m, 9.6 m)이 있어요
   - 오른쪽에는 꾸밀 방 목록(01 거실, 02 안방 …)이 있고, 누르면 그 방 꾸미기로 들어가요. 가구를 놓은 방은 "가구 2개"처럼 초록 점으로 표시돼요
   - 장면 아이디어: 평면도 → [3D 위에서]로 집 전체가 입체로 솟아오름 → [3D 안에서 걷기]로 안방에 서 보기 → 목록에서 안방을 눌러 가구 놓기
7. **방꾸미(방 하나 꾸미기)**: 가구를 놓고 2D·3D로 보기. 문제·개선 제안 피드백, 아이 눈높이(90cm) 보기 (그림 10)
8. **AI 상담 챗봇**: 대화로 집 찾기("달서구, 전세 2억 5천 이하") + 판정 설명·계약 전 확인 질문에 답해요 (그림 14)
9. **휴대폰 화면**: 모든 화면이 휴대폰에 맞춰져 있어요 (그림 15)

## 4. 꼭 넣어야 할 "추가 기능" — 실제로 작동하는 것처럼 연출해 주세요

아래 두 기능은 **코드는 다 만들어져 있지만** 외부 서비스 승인을 기다리는 중이라 지금 사이트에서는 결과가 비어 있어요.
영상에서는 **실제로 작동하는 것처럼 자연스럽게** 보여 주세요. 화면 모양은 참고 그림을 따라 주세요.

### 4-1. 원룸·투룸·오피스텔 전월세 (그림 12, 13)
- 국토교통부 전월세 실거래가(연립·다세대, 단독·다가구, 오피스텔)를 받아 대구 전체의 원룸·투룸·쓰리룸·오피스텔 계약을 보여 주는 기능이에요.
- **전월세 화면**: 위쪽 칩 [전체 / 원룸 / 투룸 / 쓰리룸 이상 / 오피스텔], 구·군, 전세/월세, 보증금·월세 상한 필터, 카드 목록
  - 카드 예: "월 450,000원 · 보증금 5,000,000원 / ○○빌라 / 수성구 범어동 · 24㎡(7.3평) · 3층 · 2015년 준공 / 계약 2026-10-12"
- **지도의 "전월세 기록" 단추**: 누르면 건물 자리마다 파란 점이 생기고, 점을 누르면 그 건물의 월세·전세 중간값과 최근 계약 목록 카드가 열려요.
- 장면 아이디어: 사용자가 "원룸"과 "월세 50만 원 이하"를 고르면 목록이 줄어들고, 지도로 넘어가 파란 점을 누르면 카드가 열리는 흐름.
- 지켜 주세요: 카드에는 **"신고된 지난 계약이에요 · 지금 나와 있는 매물은 아니에요"** 문구가 있어요. 영상에서도 "지금 매물"이라고 말하지 말아 주세요.
- 주의: 그림 12, 13의 "예시 빌라 ○" 같은 건물 이름과 금액은 화면 모양을 보이려고 잠깐 넣은 **시연용 예시 자료**예요(출처 칸에도 "시연용 예시"라고 나와요). 영상에서는 그럴듯한 건물 이름과 현실적인 금액으로 바꿔 주세요.

### 4-2. AI 실사 렌더링 (그림 11)
- 방꾸미 3D 화면에서 가구 배치를 끝내고 **[AI 렌더링]** 단추를 누르면, 같은 배치를 **실사 사진처럼** 바꿔서 창으로 보여 주는 기능이에요(Gemini 이미지 모델 연결).
- 장면 아이디어: 3D로 단순한 상자 모양 가구가 놓인 방 → [AI 렌더링] 클릭 → "만드는 중…" → 같은 자리·같은 크기의 실제 가구와 햇살이 들어오는 실사 사진이 창에 나타남 → [사진 저장].
- 결과 사진에는 **"AI 연출 이미지·치수 참고용"** 배지가 붙어요. 영상에서도 이 배지를 보여 주세요.
- 가구의 종류·개수·자리는 3D 화면과 같아야 해요(가구를 더하거나 옮기지 않기).

### 4-3. 연출 표시 (선택안도 같이 제시해 주세요)
- 기본안: 위 두 기능을 실제로 작동하는 것처럼 자연스럽게 보여 주기
- 선택안: 해당 장면 구석에 작은 자막 "외부 데이터 연결 후 화면 · 연출"을 넣은 버전도 함께 제안해 주세요 (사이트 원칙: 예시·연출 화면은 표시한다)

## 5. 영상 기획에서 원하는 것

1. **길이 두 가지 안**: 90초 버전, 3분 버전 (장면별 초 단위 표)
2. **장면 표**: 장면 번호 / 시간 / 화면(어느 그림·어느 기능) / 동작(무엇을 누르는지) / 자막 / 내레이션
3. **내레이션 대본**: 해요체, 짧은 문장
4. **장면 전환·음악 분위기 제안**: 밝고 따뜻한 느낌(방봄 디자인: 따뜻한 흰 바탕 #f3f2ee, 검정 글자 #141714, 포인트 초록 #1f6b4f 하나, 영문 포인트는 기울인 세리프체)
5. **화면 녹화로 찍을 장면과 AI로 만들 장면 구분**: 3장의 기능은 실제 화면 녹화, 4장의 두 기능은 AI 연출
6. **시연용 입력 예시**: 예) 27세, 월 실수령 2,500,000원, 모은 돈 45,000,000원, 월 예산 600,000원
   (사이트에는 예시 사람이 없으니, 영상 안에서만 쓰는 입력값으로 써 주세요)

## 6. 쓰면 안 되는 표현

- "대출 가능", "전세 가능", "안전매물", "보증금 안전", "시세보다 확실히 저렴" → 대신 "요건 충족 / 확인 필요 / 미충족", "확인할 것이 다 보이는 집"
- "방봄이 청년 유출을 막는다" 같은 인과 표현 → "결정을 돕는다"
- 경쟁사 이름(부동산 앱 이름)을 직접 말하지 않기 → "일반 부동산 앱과 다른 점"
- 판정·승인은 각 기관이 한다는 점을 한 번은 말해 주세요 ("최종 결정은 각 기관이 해요")
- 이모지 쓰지 않기
